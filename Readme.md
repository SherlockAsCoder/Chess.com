### Project Overview

This module is a clone of Chess.com, featuring the ability to:

- Play chess with players from around the world

- Watch ongoing matches as a spectator

- Share your matches with others so they can watch in real time

#### Development

Install the dependencies and start the development server:

```sh
npm install
npm run dev
```

Open http://localhost:3000. The development command checks TypeScript types before
starting the server with `tsx`.

To check types without starting the server:

```sh
npm run typecheck
```
